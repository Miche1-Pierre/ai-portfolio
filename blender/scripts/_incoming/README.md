# Scripts entrants

Dépose ici tes scripts Blender / Python tels quels (n'importe quel nom). Je les lis, je les adapte
aux conventions de l'atelier (`lib.naming`, `lib.materials.palette_material`, `lib.mesh.finalize`,
aléatoire seedé, aucune dépendance à la sélection) puis je les range dans `scripts/assets/` (un
asset = un script) ou `scripts/lib/` (outil réutilisable). L'original reste ici jusqu'à ce que tu
valides la version rangée.
